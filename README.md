# Image-Processing-Labs

This repository contains my lab assignments for the **Image Processing** course at Imam Abdulrahman Bin Faisal University.

## Topics Covered

The course covers the following topics:

* **Introduction to Image Processing**

  * Fundamentals and applications of image processing

* **Mathematical Foundations for Image Processing**

  * Mathematical concepts and techniques used in image processing

* **Digital Image Fundamentals**

  * Digital image representation
  * Image formation and basic image concepts

* **Intensity Transformations**

  * Intensity-level transformations
  * Image enhancement techniques

* **Spatial Filtering**

  * Spatial-domain filtering
  * Image smoothing and sharpening

* **Color Image Processing**

  * Color image processing
  * Color spaces

* **Frequency Domain Fundamentals**

  * Frequency-domain representation
  * Frequency-domain processing techniques

* **Image Restoration**

  * Image degradation and restoration
  * Image restoration techniques

* **Edge Detection and Image Gradients**

  * Image gradients
  * Edge detection techniques

* **Morphological Image Processing**

  * Morphological operations
  * Image analysis using morphology

* **Feature Extraction and Image Descriptors**

  * Feature extraction
  * Image descriptors

* **Image Segmentation**

  * Image segmentation techniques
  * Applications of image segmentation

## Repository Structure

Each lab is organized separately and includes the relevant code, notebooks, images, and supporting files.
